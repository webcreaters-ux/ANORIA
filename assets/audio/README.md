# ANORIA Audio Pack

This folder is reserved for original/licensed audio assets.

Recommended production files:

- `music-title.ogg` — title theme
- `music-vale.ogg` — Whispering Vale ambience
- `music-village.ogg` — Emberfall theme
- `music-ruins.ogg` — Sunken Ruins theme
- `music-frost.ogg` — Frostspire theme
- `music-boss.ogg` — Night King battle theme
- `sfx-sword.ogg` — weapon hit
- `sfx-magic.ogg` — spell cast
- `sfx-hit.ogg` — damage
- `sfx-heal.ogg` — healing
- `sfx-loot.ogg` — item pickup
- `sfx-levelup.ogg` — level up

The current game remains playable without these files because its fallback audio is generated with Web Audio. Only add audio that ANORIA owns or is licensed to distribute.
